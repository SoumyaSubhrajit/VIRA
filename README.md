# VIRA Project

Welcome to the VIRA project. This repository contains the complete suite of tools and data needed for VIRA.

## Repository Structure

- `/operator` - The Next.js web application and main operator dashboard.
- `/Data` - Contains local data or Excel files.
- `/AI Prompt` - Contains prompts and resources for AI interactions.
- `/.github` - Contains project templates, CI/CD pipelines, and Dependabot configuration.

## Getting Started

To run the `operator` web application:

1. Navigate to the operator directory:
   ```bash
   cd operator
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
